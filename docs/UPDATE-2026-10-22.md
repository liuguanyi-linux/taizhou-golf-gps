# 更新可靠性优化 · 2026-10-22（2026-10-23 提交仓库与在线版）

本轮基于已发布 1.0.0，集中修复更新过程中可能干扰编辑的问题，不修改任何球场基线几何、图片或用户项目。2026-10-23 更新范围为仓库源码、文档、测试及 GitHub Pages 在线版；应用版本号和已发布的安装包保持不变。PWA 通过资源内容哈希识别此次更新；下次桌面安装包发布需提升应用版本并重新构建。

## 修改

- PWA 在用户确认保存后，还会检查同一应用范围内的其他窗口（含未受当前 worker 控制的窗口）。存在其他窗口时暂停激活，请先保存并关闭其他窗口后重试。不关闭窗口、不清除草稿。
- 无法读取窗口列表时拒绝激活。来自其他网站、应用范围外或没有来源的消息不触发更新。
- 检查新版失败或没有新版本时，隐藏上一轮遗留的下载按钮，避免误操作。
- PWA 等待激活超过 15 秒时恢复按钮并显示重试提示。只有当前页面明确请求更新且仍处于等待状态才因控制器切换刷新；超时后的迟到切换不自动刷新。
- 安装入口改为仓库版本列表，不再固定指向 1.0.0。

## 验证与边界

`tests/service-worker-test.cjs` 覆盖单窗口激活、多窗口拒绝、无关范围窗口、无来源/错误来源、枚举失败、离线导航、API 排除与不清理项目。

新增 `tests/app-client-test.cjs` 覆盖检查失败后的旧按钮清除、确认保存/取消、可信 worker 消息、多窗口拒绝后重试、激活超时、迟到消息不刷新以及版本列表链接，加入 `npm test`。

2026-10-22 整套 `npm test` 通过。本机浏览器已实际打开“帮助与下载 → 应用 / 更新”，检查更新返回“未发现待安装更新”，下载帮助链接正确指向仓库版本列表；多窗口拒绝与超时分支仍以自动测试覆盖，尚未完成真实浏览器两版本切换验收。

这些属于模拟 Service Worker 和 DOM 的自动测试，不等同于 iOS 真机或两版本安装升级测试。窗口检查和浏览器切换并非操作系统级原子锁：请仍在保存备份后关闭其他工作台窗口，并且切换期间不要新开编辑窗口。旧 1.0.0 的等待页面接到新 worker 的拒绝消息时，可能尚不具备新提示；请保存后关闭多余窗口，再重新打开应用。

此次不提升 GPS 的实地精度，不增加云同步，也不进行无确认自动安装。公开下载的 1.0.0 安装包不包含此次优化，桌面应用检查更新不会因此获得新的安装包。网页版更新前请先保存并导出重要项目，再关闭其他工作台窗口进行更新。
