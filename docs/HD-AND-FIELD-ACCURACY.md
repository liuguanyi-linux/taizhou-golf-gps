# 多球场高清制图与实测精度检查

更新：2026-09-11。作用于独立项目本机副本，不修改原网站后台。

## 使用流程

1. 地图页搜索球场，接入独立项目。已有逐洞数据直接使用；没有则先读取公开地图，核对边界、洞号与要素，或沿卫星图描绘。
2. 编辑器左侧最上方选择 2K / 3K / 4K，点击 **生成本洞高清虚拟图**。批量按钮只生成尚未绑定图片的洞，不覆盖已有图片。无有效几何的洞会跳过并说明原因。
3. 点击 **打开高清图 · 放点 / GPS**。选择“放置球车”或“放置目标点”，在图片上点击；支持拖动已有点、滚轮居中缩放、全图复位。左侧始终是独立滚动的操作区。
4. 在图片内选择测距起点及目标，可选择其他洞的点位。显示地表直线距离；不是车道行驶里程。只有已绘制真实车道才可模拟车道移动。
5. 导出 PNG 和完整项目包。项目包包含当前图、保留的上一版图片、配准、球洞几何、自由点及精度检查资料，可导入另一个浏览器的独立副本。

## 生成内容与坐标

这是高分辨率**制图风格**，不是航拍摄影或此前手工美术图风格。草纹、阴影与配色是装饰，不增加真实地物。不存在的数据不虚构：没有沙坑、车道、树木坐标，就不画这些对象。

`course-workspace/hd-map.js` 将本洞已有 WGS84 点线面投影到局部米制平面，以 Tee 至果岭方向朝上（缺少起终参考时北向上），等比例绘制，保留完整范围和边距。长边选项实际控制画布高度，横向按完整几何自适应；横宽不小于 1000 px。不重塑球道轮廓，不把中线当车道。

生成的 `hole.visual` 保存：`asset_id`、宽高、四角配准点、生成器版本、时间、原始几何快照签名、未知精度。四角点来源是 `generated_projection`，不是现场测量。现有仿射配准编辑器使用这些点，维持同一坐标关系。数学往返误差极小不代表地理来源准确。

修改地理要素后会提示图片过期，需重新生成。替换图片必须显式勾选；上一版在 `visual_previous` 中保留，可恢复。图片编辑的球车等自由点是独立覆盖层，不必每次重绘底图。

## 实地精度检查

展开 **实测精度检查 / 校准依据**。可直接选择本洞地图点、填写同一地物的现场经纬度、测量来源、仪器、参考精度与实际采集时间，点击加入；也可导入 JSON。

```json
{
  "coordinate_system": "WGS84",
  "threshold_m": 2,
  "points": []
}
```

每个点有 `id`、`role`（control 或 check）、`map`、`measured`（经度在前）、`source`（rtk / survey / gnss）、`instrument`、`accuracy_m`、`observed_at`。模板不填示例经纬度，防止把测试值当实测值。普通浏览器定位不是默认的高精度测量源。

`course-workspace/field-audit.js`：

- 控制点只估算平均东西 / 南北偏移，不计入独立检查。
- 检查点报告原始误差、RMS、最大误差和覆盖面积；偏移建议的检查残差单列，**不自动改动任何地图坐标**。
- 重复位置不算多个独立点。当前工具的保守门槛：至少三个独立点、凸包面积至少 10 平方米、声明参考精度不大于容差的三分之一、各检查点误差不超过容差。此门槛是工具策略，不是测绘行业认证标准，也不证明覆盖整个球洞。
- 报告只针对提交的地图 / 实测对应点快照；地图后续改变需要重新采样检查。仪器精度、输入来源由用户声明，软件不能鉴真。
- 所有报告均 `scope: submitted_checkpoints_only`、`field_verified: false`。即使通过门槛也只显示“所提交检查点在容差内”，不宣称全场达到厘米级或米级。

当前并没有该球场的实地测量数据，因此交付的是生成、编辑和检查工具，不是已完成实地精度认证的数据。具体目标精度要先约定，再以可靠现场测量及分散独立检验点验证；图像分辨率无法替代测量。

## 校准入口的边界

原有“图片 ↔ 地图配准”支持录入已知 WGS84 对应点重新拟合，以及独立检验点。生成图已自动对应现有地图坐标。若现场发现底层地图整体或局部偏移，应在真实地图中修正对应地理点线面、重新制图，然后重新独立检验；不能只把好看的图片移动几像素，声称底层地图也已校准。本次只增加偏移建议和检查报告，没有自动整体纠偏按钮。

## 验证

`node scripts/check.cjs` 包含 2K/3K/4K 画布边界、旋转球洞、300 个新图片坐标往返点、现有 1000 点配准回归、无几何拒绝生成、源数据不变、实测检查角色隔离、不足 / 重复 / 共线检验点、弱参考精度、错误坐标系与缺少上一版图片等测试。合成测试只能验证软件计算，不能验证球场实地精度。

浏览器使用本机佘山草稿实际生成 18 洞图片；验证切洞、图片内跨洞测距及图片放置球车后 WGS84 保存。源数据仍稀疏，第 8 洞果岭类型问题未被自动猜测修复，因此图面细节并未与完整测绘图等同。
