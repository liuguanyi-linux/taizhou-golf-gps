# 简洁版高清编辑器 · 2026-09-16

## 日常操作

1. 地图页选球场，再选球洞。
2. 点击顶部 **高清虚拟图**。有原图则打开原图；没有图片但有地图几何时，生成本洞高清图并打开；没有地理要素时会提示补充，不能凭空生成测绘数据。
3. 点击 **放球车** 或 **放目标点**，在图上点击一次。放下后自动回到 **移动 / 拖点**，可以拖动已有点。
4. 选择测距起点和目标。距离随点位变动刷新，支持跨洞目标。
5. 点位自动保存到当前浏览器。顶部 **保存** 也可手动保存；交付客户使用 **返回地图 → 下载项目**，先核对内容再下载。

滚轮与加减按钮缩放；拖动空白平移；**全图** 恢复完整图片。缩放只影响画布，左侧操作栏和上方工具栏不随图片放大。

## 展开的功能

- **更多点位 / 绘制路线**：Tee、果岭旗、球车道。
- **实时 GPS / 车道模拟**：设备定位与路线测试。手动点、模拟点、实时 GPS 不是同一种数据来源。
- **坐标校准（高级）**：上传图片、控制点与独立检查点。未配准的美术图不能直接用于 GPS。
- 地图页侧栏 **生成与检查 → 画质 / 更新已有图**：2K / 3K / 4K 生成；更新已有图需要明确勾选允许替换，保留上一版可恢复。批量生成只处理缺图球洞。
- **地图点线面编辑**：原有地图编辑工具。
- **更多工具**：识别、图片版本、实测检查、完整项目管理等。

## 图像和坐标的边界

`coordinate-hd/2` 使用程序纹理和本地草坪材质，改善球道条纹、水面、沙坑边缘与已有树木的表现。几何由原有 WGS84 数据决定，图像配准使用同一个投影，不根据装饰纹理反推坐标。

草坪材质通过内置图像生成工具制作，提示词与资产路径见 [材质说明](../course-workspace/assets/README.md)。缺失材质时回退到程序纹理。没有道路、树带或沙坑数据时，不会凭外观自动补造这些地物。

这仍是坐标驱动的高清地图，不等于以前逐洞制作的精细美术插图，也不是新测绘成果。已有美术图保留，使用前仍需校准及现场检查。输出 `accuracy_m` 保持未知，不因像素增加或转换残差很小而宣称实地精度提高。
