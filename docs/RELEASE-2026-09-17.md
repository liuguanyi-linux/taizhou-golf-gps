# v2026.09.17-tool-preview · 通用球场制作工具

公开开发预览，非现场测绘认证成果。本版按拥有者要求归档当前工具和技术文档，不发布其浏览器私有草稿或整个原网站源码。

## 包含内容

- 地图检索球场、原站逐洞数据只读接入、独立副本、1–72 洞项目。
- WGS84 点线面编辑、卫星地图与高清图共用坐标、自由球车和目标点、跨洞测距。
- 2K–4K 坐标驱动制图、草纹材质、配准控制点、旧版图片保留。
- 公开地图候选确认、卫星颜色轮廓提取、本机 CLIPSeg 试验入口，均需人工核对。
- 图片与数据完整包、逐洞缺失清单、实测检查点报告。
- 本地克隆网站资源安装器与后台适配说明；不含原站整套后端。

## 浏览器验收

样例为泰州 cn0000385 独立测试副本。搜索、读取 18 洞、单洞 2048 px 生成、图片内新增球车、拖动 Tee、绘制路线、测距、保存刷新全部通过。

导出包为 39,610,507 字节，含 18 洞、19 份图片（包括一个保留旧版本）；通过文件选择器重新导入成功。Tee、球车、路线、图片配准控制点逐字段一致。测试车到旗杆显示 268.4 m，导入后不变。路线模拟距旗数值随位置更新。滚轮放大后侧栏可见。

## 明确限制

- 旧有 18 张美术图不等于有效配准。本轮只重新生成第 1 洞，其他 17 洞需生成或校准；几何编辑后底图会提示重绘。
- 约 40 MB 包通过文本框粘贴的测试发生超时与测试连接中断，原因未定；文件导入通过。
- 本次测试浏览器后台入口跳到登录页，未执行真实后台保存/发布。
- 没有现场 GNSS/RTK 或实车验收，不保证米级或厘米级。坐标变换一致不是实地准确。
- 源地图无逐洞数据时，无法仅凭名称可靠生成完整地图；模型和公开地图可能漏检、错分、缺少车道。
- 新高清图为坐标驱动制图风格，不是旧版精细写实美术图的自动复刻。
- GitHub Pages 不运行本机 API、模型或数据库，访问本机原站需本地部署。

## 复现与下载

运行 `node scripts/check.cjs` 进行结构、算法和适配回归；运行 `node scripts/serve.cjs` 打开本机工具。地图及影像外部来源需网络和相应使用权。完整项目的大包使用文件导入。

源码 ZIP 由本版本 Git 提交生成，不含 .git、依赖缓存、模型权重、密钥和浏览器个人轨迹。下载页提供 ZIP 的 SHA-256 校验值。资源清单为 `downloads/manifest-sha256.json`。
