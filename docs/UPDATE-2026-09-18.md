# 2026-09-18 定位状态与测距可靠性更新

## 本次修复

- 将浏览器定位封装为独立会话。停止、重启或拒绝权限后，旧会话迟到的成功／错误回调不能恢复旧定位。
- 定位超过质量门槛、过期或暂时失败时清除当前 GPS 点及其距离；新有效观测可以恢复。权限拒绝则停止会话，允许用户重新启动。
- 真实 GPS 与路线模拟显式分开。停止模拟后不再把最后一个模拟坐标当作当前位置；GPS 不可用时不自动退回模拟点或目录里的第一个点。
- 切换页面时释放定位监听与计时器；页面恢复时恢复质量检查计时器，定位需重新启动。
- 地图与高清图测距同时说明起点、终点的精度来源。只有设备端声明精度，并不能证明目标点或两点距离具有同样精度。

不改变保存的 WGS84 坐标，不对真实定位做强制吸附、平滑或美化。路线模拟仍沿用户提供的路线计算，不是实测车辆轨迹。

## 实现

`course-workspace/gnss-session.js` 负责生命周期与迟到回调隔离，`gnss-quality.js` 负责质量判断与两端点提示，`editor.js` 负责地图状态和定位／模拟切换，`image-editor.js` 共享同一状态与距离说明。

会话包含 idle、waiting、tracking、rejected、denied、error、stopped 状态。每次取消递增会话代号；回调必须属于当前会话且会话仍有效才可更新位置。监听标识为 0 也会正确释放。

## 验收

执行 `node tests/gnss-session-test.cjs`：9 项自动测试通过，覆盖停止后迟到回调、重启隔离、重复启动、过期与恢复、即时提高门槛、权限拒绝、同步回调、API 不可用、临时超时、状态拷贝隔离和双端点质量说明。完整回归通过 `node scripts/check.cjs`。

本机浏览器使用独立的“全流程验收 0916（非实测） · 导入”项目，未写入原网站后台或客户项目：

| 场景 | 本次实际结果 |
| --- | --- |
| 选择无有效数据的设备 GPS，停止并保存 | 保留 GPS 选择，距离显示 — m；不切换静态点 |
| 高清图启动本洞路线模拟 | 显示 image-live 与“路线模拟（非实测）” |
| 高清图停止模拟 | 起点清空、距离隐藏，显示未启用定位或路线模拟 |
| 再手工选择测试车 A | 高清图恢复 268.4 m，起点与终点均提示精度未知 |
| 同一对点回到地图 | 同为 268.4 m，标明直线距离而非车道长度 |
| 保存并刷新 | 两个自定义点的全部字段、三个路线节点及果岭旗坐标逐字段一致 |
| 页面脚本错误检查 | 未发现 error 日志 |

GPS 权限拒绝、断流和迟到回调由自动测试中的模拟定位适配器覆盖，本次没有操作真实接收机、没有在球场外业测试。268.4 m 是输入坐标的计算值，不是测距仪真值。

## 仍需现场资料才能完成的部分

本次提升的是定位状态和测距信息的可靠性，不是已证明的米级／厘米级实地精度。仍需可靠的控制点、独立检验点以及真实 GPS／RTK 观测验证。设备 JSON 快照接入不等于已完成串口、蓝牙、NTRIP 或持续多车服务器连接。

已有发布标签 `v2026.09.17-tool-preview` 保持不变；本次更新随 `codex/delivery` 分支发布。完整项目包仍不含浏览器个人草稿或本次合成验收点。
