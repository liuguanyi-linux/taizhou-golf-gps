简洁工作台

这是现有网页工具的统一操作界面，不是独立安装的桌面软件。不修改项目格式、WGS84 坐标、GPS 质量门槛或原站数据。

日常操作

  • 在 cn/map/ 搜索球场，打开已有项目，选择球洞。
  • 左侧“制作”只保留一个下一步按钮，按数据状态提示补地图、生成图片或打开图片。缺少地物时仍需要核对和补绘，不能仅凭球场名字生成可靠实测数据。
  • “放点测距”中选择球车、目标点、果岭旗或球车路线，点击“在图上放置 / 绘制”，再点击地图。点位可拖动；选择起点和终点查看直线距离。
  • 顶部下拉菜单切换卫星地图、高清虚拟图和矢量地图；“预览”打开球车界面，“保存”保存本机数据，“导出”检查后下载包含图片的完整项目包。
  • 手机上点“工具”展开主侧栏；高清图上点“点位工具”展开图片编辑。放点时自动收起侧栏，地图不会被永久挤窄。滚轮缩放和“全图”保留。

地图放点或画路线时，底部会出现当前操作提示和“取消”，不必重新打开侧栏。放点后提示自动消失；路线沿车道依次点选，再点最后一个节点完成并自动保存。取消只丢弃未完成的绘制，保留已有点线。这个提示仅在操作时出现，不增加常驻按钮。视图切换期间暂时锁定下拉菜单，避免重复触发。

高级功能在哪里

  • “高级”：点线面编辑、生成参数、批量生成、候选识别、项目管理。开启“地图点线面编辑”才显示地图绘图工具栏。
  • “放点测距 → 坐标与定位高级设置”：精确经纬度输入、RTK、多车快照、静止采点、数据节点和单项导出。
  • 高清图中的“坐标校准（高级）”：图片上传、对应点、独立检查点。
  • 网站集成模式的“高级 → 网站后台保存 / 发布”：原有显式草稿保存和发布确认仍保留，普通“保存”不会自动发布。

已有项目、按钮内部 ID、处理函数和数据格式保持兼容。界面只重新组织原有节点，不复制数据模型或另建定位状态。切换工作区会结束绘图和编辑模式，避免遗留的删除/拖动模式影响下次放点。

手机 / 平板球车预览（2026-09-29）

  • 顶部“预览”沿用当前项目、球洞与点位。前沿 / 中心 / 后沿使用编辑器同一份地理数据，显式前后标记优先；没有果岭边界时不编造前后距离，只有旗杆时显示“至旗杆”。果岭前后按球洞数据方向定义，不是实时车辆视角的最近 / 最远边界。
  • 计算果岭参考中心前排除首尾重复的闭合节点，避免 Leaflet 开环和 GeoJSON 闭环表示之间切换造成参考距离变化。此修复只影响派生参考点，不更改原始边界或实测点，也不代表真实设备精度提高。
  • 有效配准的项目高清图片会直接复用，不再强制重绘成简图；图片实际尺寸必须与配准记录一致。未配准、无图片资源时显示原因并回退坐标制图，生成材质不是实测影像。原有图片不会被覆盖。自动制图使用 3K 长边；这只改善显示清晰度，不增加测绘精度。
  • 拖动白色目标点、静态球车时保留手指抓取偏移，避免点从图标中心跳到手指下。微小抖动不会修改测距目标；缩放和“全图”只改变相机，不改变 WGS84 坐标。实时 GPS 不能当作静态球车拖动。
  • 手机预览限制在视口宽度内。大数字、前后沿距离、地图、测距面板各占独立区域；没有增加常驻操作按钮。详细来源可在“坐标与精度”展开查看。
  • 手机 / 平板 GPS 仍受设备和环境影响。默认 2 m 输入门槛可能使手机定位长期不被采用；现在会显示设备报告值、门槛与未采用原因。可在“放点测距 → 坐标与定位高级设置”调整，但放宽门槛不等于提高准确度。显示的 95% 半径为设备声明，不是本工具完成的现场认证。参见 W3C Geolocation。

程序测试覆盖 18 洞共享目标距离、旋转缩放逆变换、抓取偏移、高清图片配准准入及资源失败回退。图片加载选择测试使用合成资产，不属于实测配准验收。浏览器 390 × 844 视口中修复前地图宽 556.95 px，修复后宽 370 px、两侧各 10 px；第 1 洞静态黑 Tee 示例前 / 中 / 后为 362 / 379 / 396 m。临时目标拖动后显示坐标 [120.0724707, 32.6141949]，缩放并复位后坐标不变。这些是软件测试，不是手机现场 GPS 误差。

历史验收

图片校准向导（2026-10-12）

打开“制作 → 打开图片 · 校准坐标”。图片侧栏现在直接显示一个下一步按钮，无需先展开高级菜单找经纬度输入：

  • 点击“开始坐标校准”，在卫星地图选择一个清晰地物。
  • 自动返回图片后，点击同一地物。对应点自动保存；两个选点阶段都有取消入口。
  • 继续添加对应点。至少 3 个不共线点才可转换，建议 5 个以上分布于起点、终点和两侧。不要只沿球道中线放点。
  • 建立有效配准并补足对应点后，主按钮改为“添加独立检查点”。检查点使用新的地物，不参与拟合，不能复用已有对应点。

配对期间自动显示绿色控制点覆盖轮廓，覆盖外区域变暗；控制点标“配”，检查点标“检”。“图片覆盖”是控制点凸包占整张图片的面积比例，不是球场覆盖率或定位精度。范围之外仍禁止从图片推算新点。独立检查显示最大偏差，以及被排除的重复/无效点和覆盖外检查点数量；这些结果仅比较所给地物坐标与图片配准，不认证手机现场精度。图片实际尺寸和配准记录不一致时停止映射，不带着旧坐标继续编辑。

“坐标校准（高级）”保留 JSON 导入和撤销。撤销按钮随所选类型明确显示“对应点”或“检查点”，只影响该类最后一个点；保存失败恢复内存中的旧配准。导入成功会清除之前的错误提示。手机上重新展开“点位工具”回到向导顶部，选图片位置时自动收起抽屉，全图适配为临时提示栏预留空间。
