# 精度输入、RTK 快照与配准检查

2026-09-17 精度质量检查更新。此更新不改变已经发布的 `v2026.09.17-tool-preview` 标签；该标签是优化前的可复现基线。

## 现在可以做什么

- 编辑器 → GPS 测距 → **定位质量 / RTK 接入**：浏览器定位默认要求声明的 95% 水平误差半径不超过 2 m，采集时间不超过 10 秒。门槛可改为 0.01–100 m；改小不会改善接收机信号，只会拒绝更多位置。
- 定位过期、精度未知、倒序、时间超前或明显跳变时不再显示为当前 GPS。保留原始坐标，不将车辆吸附到道路来伪造准确性。
- 导入外部接收机的 **WGS84 JSON 快照**，保留仪器、采集时间、固定解状态、水平误差半径、置信度、差分龄期；一批中任一点不合格则整批不接入。
- 高清图显示设备精度声明；GPS 未通过时不拿模拟球车替代。快照不是连续定位服务，历史点仍可作静态测距，不能当成当前位置。
- 配准排除重复检验点、与控制点同坐标的伪独立点；5–100 个控制点增加留一交叉检验，帮助发现错配点。显示图上比例、独立检验最大误差，避免把图片分辨率当成现场精度。

## 设备快照格式

下面是**合成格式示例，不是球场实测数据**，时间固定，直接导入应因过期被拒绝。接入时由设备适配器填写真实观测及其采集时间，不要为了通过检查改写旧观测时间。

```json
{
  "coordinate_system": "WGS84",
  "positions": [{
    "id": "cart-a",
    "name": "球车 A",
    "coordinate": [120.0, 32.0],
    "updated_at": "2026-01-01T00:00:00Z",
    "accuracy_m": 0.04,
    "accuracy_confidence": 0.95,
    "fix_type": "rtk_fixed",
    "correction_age_s": 1,
    "receiver": "设备型号和序列标识"
  }]
}
```

`coordinate` 为 `[经度, 纬度]`；必须与地图控制点处于可比的地理参考框架。不能仅将 GCJ-02、地方坐标或 CGCS2000 标成 WGS84。高精度应用还需确认参考框架实现、历元和设备/测绘软件的转换约定。

`accuracy_m` 必须是设备或经过验证的适配器给出的 **95% 水平误差半径**。HDOP 无米单位；单轴标准差、CEP、RMS、1σ 不能直接填在这里。GGA 的固定解标识本身也不是米级精度值。没有这一指标就不通过此严格入口，可在普通“离线点位导入”中以未知精度留档。

RTK 快照要求固定解、差分龄期 0–10 秒、观测不超过 10 秒；同设备相邻观测按 20 m/s 加双方声明误差半径检查异常跳变。这只是拒绝规则，不能保证所有错误都被发现。接收机声明可被伪造，本工具不认证硬件或基站。

本版本**未实现**串口、蓝牙、NTRIP、WebSocket 持续流或接收机驱动；不要把 JSON 接口描述成已经连通真实 RTK 设备。需要在确认具体硬件协议后实现适配器，不能猜测硬件数据含义。

## 测绘精度如何验证

1. 使用有来源的正射影像和分布均匀的实测控制点；至少 3 个非共线点可拟合，建议 5 个以上覆盖全洞。当前使用局部 WGS84 仿射，不是摄影测量束平差。
2. 另外保留不参与拟合的实测检验点。控制点和检验点同坐标（1 cm 内）或同图片点不会作为独立检验重复计数。
3. 留一检验是在已有控制点中逐个剔除再预测，不是独立现场验证；生成图的控制点来源相同，即使两种残差为零，也不能证明实地精度。
4. 在“现场精度核验”导入独立观测，检查 RMS、最大偏差、覆盖范围、日期和仪器。地图端误差与球车 GNSS 误差必须分别考核，未知目标点误差时不能承诺两点距离精度。
5. 标记、线、面仍使用同一 WGS84 数据。仿射控制点覆盖以外不允许图片点击推算 GPS；手绘美术图的局部非线性变形不会被增加像素数量消除。

截至本更新，没有新的 RTK 外业观测或独立测量真值，**实际水平精度仍未验证，不能声称达到厘米级或指定米级**。要实质提高绝对精度，需要接入可靠实测坐标/控制点；无人机正射重建和 RTK 可作为输入来源，不包含在当前静态工具中。

## 官方参考

- [W3C Geolocation](https://www.w3.org/TR/geolocation/)：accuracy 的 95% 水平误差半径含义；高精度请求是提示，不是硬件精度保证。
- [Emlid NMEA 格式说明](https://docs.emlid.com/reachrs2/specifications/nmea-format/)：不同消息提供位置、解状态、误差统计与日期时间；应按接收机协议组合解析。
- [OpenDroneMap 精度说明](https://docs.opendronemap.org/map-accuracy/)：区分相对与绝对精度，控制点和影像采集质量影响结果。

## 验证范围

`tests/gnss-quality-test.cjs` 使用合成输入检查过期、未来、倒序、跳变、浮点解、精度/置信度/差分龄期缺失、导出元数据。`tests/golf-registration-regression.cjs` 检查双向转换、范围拒绝、退化拟合、重复检验点和留一偏差。通过这些测试不等于通过球场外业验收。
