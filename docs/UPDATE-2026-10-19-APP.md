## 重要限制

首版没有 Windows 代码签名或 Apple Developer ID 公证，系统可能提示来源未知或阻止运行。只从本仓库下载，并对照 Release 中 SHA256SUMS.txt 校验；不要关闭系统整体安全保护。

更新按钮当前是“检查 → 下载对应新版安装器 → 保存退出 → 用户安装”，不是静默自动安装。iOS 使用在线 PWA，不提供 IPA。PWA 首次使用和未缓存高清图/卫星瓦片需要联网。

原站搜索依赖使用者自己的本机公开数据服务，发布不包含朋友的服务端、账号、私有草稿或设备轨迹。不同设备没有自动同步；原浏览器与桌面应用请通过导出/导入项目迁移。

## 复现与文件

`npm ci` → `npm test` → `npm run pack:mac` / `npm run pack:win`。

Release 标签 `app-v1.0.0`，安装包为 `Golf-Workbench-1.0.0-win-x64.exe`、`Golf-Workbench-1.0.0-mac-arm64.dmg` 和 `Golf-Workbench-1.0.0-mac-x64.dmg`。构建产物位于忽略的 `dist/`，只作为 Release 附件，不加入 Git 源码历史。
