# 球场工作台应用版

首版 `1.0.0` 为未签名开发预览，沿用现有地图、图片配准与 GPS 代码，不增加实地精度承诺。分发目标是 Windows x64、Mac Apple Silicon / Intel、iPhone / iPad 主屏幕应用。

## 安装

- Windows：在 [应用发布页](https://github.com/liuguanyi-linux/taizhou-golf-gps/releases/tag/app-v1.0.0) 下载 `win-x64.exe`，安装后启动。无需 Node、Docker 或终端。
- Mac：Apple 芯片下载 `mac-arm64.dmg`，Intel 下载 `mac-x64.dmg`，打开后将应用拖入 Applications。首版没有 Developer ID 签名和公证，Gatekeeper 可能阻止启动；不要关闭系统整体安全保护。仅在确认来源和校验值后，按系统“隐私与安全性”提示授权，企业设备可能禁止运行。
- iPhone / iPad：Safari 打开 [在线工具](https://liuguanyi-linux.github.io/taizhou-golf-gps/cn/map/)，分享 → 添加到主屏幕 → 作为 Web App 打开。这不是从 GitHub 安装 IPA，不要求越狱或企业证书。操作说明见 [Apple 官方指南](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)。

## 更新按钮

选场页“帮助与下载”内、编辑器顶部均有“应用 / 更新”。

桌面首版：检查 GitHub 中 `app-vX.Y.Z` 发布及匹配系统/架构的安装包，只接受本仓库 HTTPS 下载地址，不接收任意执行命令。发现新版本后点击下载，保存并备份，退出旧版，再安装或替换。**这不是静默升级，也不是应用内下载后自动安装。** 原生自动安装更新尤其在 Mac 需要签名；后续具备证书后单独接入并做跨版本验证。

iOS / PWA：点击检查更新下载新的应用代码缓存；新版本准备好后，先保存并导出，再点击“保存完成，重新打开新版”。不在绘图过程中强制刷新。不删除 IndexedDB、localStorage 或用户项目；不缓存 GPS 接口、原站 API 或第三方卫星瓦片。在线首次启动成功后才具备基础离线能力，未导入到项目的高清原图和地图瓦片仍需要联网。系统可能回收网页存储，不能把缓存当备份。

## 数据和功能边界

- 桌面在系统应用数据目录 `GolfCourseWorkbench` 保存项目，以固定 `golf://app` 来源访问。安装路径或版本变化不会主动换来源。卸载选项不主动删除用户数据；操作系统或用户手动清理仍会丢失。
- 旧浏览器、桌面应用、iOS 主屏幕应用的数据互相独立。迁移前导出“包含图片”的完整项目包，再在新应用导入并核对。没有云同步，不自动上传客户坐标。
- 包含已有球场几何和高清图，支持本机自由编辑、导入导出、配准和测距。
- 原站球场搜索仍依赖使用者本机 8088 公共 API；没有该后台时可用内置资料、导入项目或新建场地。没有复制朋友后台、账号或服务器数据库。
- 桌面提供受限的公开地图读取桥接；网络不通或公开要素不足时不能保证自动生成完整球洞。首版不捆绑大型 Python 模型，识别入口显示未安装。
- 桌面系统定位不等于卫星 GPS。手机定位仍依赖硬件、遮挡与系统权限；打包不缩小真实误差，也不保证后台持续采点。

## 开发和发布

Node 22.21+ / 24.5+。`npm ci` → `npm test` → `npm run pack:mac` 或 `npm run pack:win`。锁文件固定构建依赖。安装包生成到忽略的 `dist/`，不提交构建目录。主进程开启 sandbox / contextIsolation、禁用 Node renderer，导航限制在应用来源；IPC 只暴露版本读取、固定仓库更新检查、打开已校验下载链接。

升级时提高 `package.json` 版本，运行 `npm run prepare:app` 生成图标、版本号及内容哈希缓存表，再构建所有目标；测试旧项目迁移、两版本更新、离线及定位权限。用 `app-vX.Y.Z` 建立 GitHub Release，上传对应三个安装包与 SHA-256 文件。最后推送 Pages 的应用代码和缓存表。不要重用旧标签或替换同名版本内容。当前发布的标记为预览版，更新检查也接受带 `app-v` 标记且对应安装包完整的预览版本。

PWA 的各版本资源缓存隔离，旧缓存保留以避免另一个正在编辑的窗口混用版本；长期使用会占用额外空间，后续可在备份后关闭所有应用窗口再由浏览器管理站点缓存。不要清理站点数据来更新软件。
