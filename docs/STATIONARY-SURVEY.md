# 静止采点与实地偏差检查

这是静态参考点采集工具，不是让行驶中的球车坐标“变准”的滤镜。不对实时车辆做延迟平均、不吸附车道、不自动平移整场地图。

## 现场操作

1. 进入球洞编辑器 → 地图放点 / GPS → 静止采点 / 实地偏差检查。
2. 在待测点放稳设备，尽量保持开阔天空视野，确认设备静止，点击开始。坐标只保存在本机页面内存，不上传第三方。
3. 收集 60 秒。至少 30 个符合现有定位门槛、相隔 1 秒且跨度不少于 30 秒的样本才可能给出候选点。浏览器权限被拒绝或设备声明精度不达门槛时，可能没有可用样本，不应反复放宽门槛冒充高精度。
4. 查看被排除样本、离散度和前后段漂移。存在明显移动/漂移时不能保存候选点。
5. 导出原始记录与报告作为备份。需要时明确点击“保存为候选参考点”；新增点的 accuracy_m 保持 null，不覆盖果岭或 Tee。原始记录不会自动进入项目包，必须单独导出。
6. 采样结束不自动关闭编辑器原有 GPS 会话；离开现场前点击“停止 GPS”。刷新页面会丢失未导出的采样记录。

## 历史记录格式

将现场接收机记录转换为下面格式后，粘贴到“分析已有定位记录 JSON”。一次只分析一个设备的同一静止点。最多 2000 条、2 MB。

```json
{
  "coordinate_system": "WGS84",
  "stationary_confirmed": true,
  "max_accuracy_m": 2,
  "samples": [
    {
      "id": "receiver-a",
      "source": "external_gnss",
      "receiver": "实际接收机型号",
      "coordinate": [120.0, 32.0],
      "accuracy_m": 0.05,
      "accuracy_confidence": 0.95,
      "fix_type": "rtk_fixed",
      "correction_age_s": 1,
      "updated_at": "2026-09-23T01:00:00Z"
    }
  ],
  "reference": {
    "coordinate": [120.0, 32.0],
    "accuracy_m": 0.02,
    "source": "survey",
    "instrument": "独立测绘成果/仪器名称",
    "observed_at": "2026-09-23T00:00:00Z",
    "independent": true
  }
}
```

以上坐标纯属格式示例，不是球场实测真值。reference 可省略；没有它只报告采样稳定度，不报告实地误差。外部 GNSS 记录沿用固定解及差分龄期检查；浏览器来源为 browser_geolocation，不捏造 RTK 状态。

## 算法和解释

- 筛选：有效数值坐标、明确时间、95% 设备声明、精度门槛、同一设备、时间顺序、至少 1 秒采样间隔。历史记录按采集时刻检查，不把旧记录显示成实时 GPS。
- 在局部米制平面求坐标中位数，以径向偏差的 MAD 剔除明显离群点，再求保留样本的平均位置。阈值下限采用 0.5 m 与设备声明中位数的两倍中较大者，避免重复/量化坐标的 MAD 为零导致过度排除。原始样本保留，排除原因可追溯。
- 前后三分之一的中位位置差用于发现移动/漂移；这是启发式检查，不是证明设备一定静止。
- P95 离散度描述采样分布，不是置信区间，也不是绝对精度。相隔一秒不意味着样本相互独立；不使用“精度除以样本数平方根”来虚构精度。
- 独立参考点提供原始 RMS/P95 与候选点偏差，仅适用于这个点及本次记录；参考点误差、天线偏置、设备坐标框架和标志点对应均需另行核验。
- 12 项合成测试包含随机扰动、离群值、共同偏移和运动。合成数据下改善不代表现场改善；加入 5 m 共同偏差后，结果仍保留约 5 m 偏差，明确揭示平均不能消除系统误差。

要继续缩小真实定位误差，需要可追溯的地图基准、合适的接收机/天线和现场独立验证；仅靠前端代码无法保证厘米级精度。

依据：[GPS.gov 定位精度影响因素](https://www.gps.gov/gps-accuracy-0)、[W3C Geolocation 设备 accuracy 定义](https://www.w3.org/TR/geolocation/)。
