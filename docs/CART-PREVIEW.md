# 球车端预览（2026-09-23，本地首版）

## 使用方法

进入球场项目的球洞编辑器，点击顶部「球车预览」。预览与地图编辑器位于同一网页，共用项目数据，不创建另一套球场。

- 拖动白色测距点，或点击地图：显示起点到目标、目标到旗杆的两段直线距离。仅改变临时测距点。
- 「保存目标点」：将临时位置保存为当前洞的 reference 点，可在编辑器查看、导出。重复保存会新增独立点。
- 「放置球车」后点击地图：保存静态球车点；不是设备实时位置。拖动选中的静态球车也会保存位置，并清除原有设备精度声明。
- 「测距起点」：选择 Tee、球车或自定义点。多球车及跨洞任意目标的完整测距继续使用编辑器；此预览的终段目标固定为本洞旗杆。
- 「使用实时 GPS」：沿用现有 GNSS 会话和质量门限；定位权限失败、位置过期或停止后，不使用静态点冒充当前定位。
- 「车道模拟」：只沿已存在的本洞路线运行；无路线时不可用。路线本身是否贴合实地车道仍需核对。
- 顶部可换洞、切换横/竖屏预览及返回编辑；滚轮缩放，拖空白平移，「全图」复位。米/码切换只改变显示单位。

## 实现与数据关系

`cart-preview.js` 是现有编辑器的同页展示层；`cart-preview-core.js` 提供纯相机正反变换和测距，`cart-preview.css` 提供球车/窄屏布局。`hd-map.js` 新增 presentation 模式：由现有 WGS84 几何绘制透明底图、草纹、水域和示意林冠材质，不改变点线面坐标。没有地理几何的球洞仍会提示补充数据，不生成假球洞。

流程：屏幕点 → 撤销相机平移/缩放/旋转 → 图片像素 → 同一制图投影的逆变换 → WGS84。距离采用现有 point-workspace 计算。目标点保存沿用现有项目保存接口，精度保持未知，而不是由坐标小数位数推断。

不覆盖用户上传的旧高清图；本预览由当前几何重新渲染。草纹、树冠、光影仅为装饰材质，不是逐树测绘、DEM 或坡度测量。现阶段不是参考图片中全部业务系统的复刻，不包含广告、计分、点餐、身份识别等后台服务。

## 已验证范围

- 新增 5 项纯逻辑测试：2,700 次相机正反变换、旋转全图边界、非法输入、缺失距离与单位转换、18 洞制图坐标往返。
- 新增 presentation 回归：共享原几何、控制点和来源签名，实地精度字段仍为 null。
- 浏览器使用独立「全流程验收（非实测）」测试项目：点击/拖动目标，两段距离由 113/159 米变为 155/115 米；保存后编辑器读出 WGS84 120.0723055738184, 32.61382914169554，刷新仍保留。
- 修复实测发现的换洞事件重入问题：停止模拟时刷新下拉框，曾把目标洞号重置；现在先捕获用户选择再停止。第 1、2 洞切换已检查。
- 路线模拟距离持续更新；停止后起点及果岭距离显示 `--`，不会沿用旧位置或回退静态球车。浏览器控制台无错误。
- 检查桌面横屏、430px 宽的内置竖屏预览与 390×844 浏览器窄屏断点；这不是实体手机/球车硬件兼容性认证。

## 精度边界

软件坐标往返一致不等于实地 GPS 精度。前/中/后缘若来自几何推导，仍然是参考位置。没有独立实测控制点和现场 GNSS 记录，不报告真实米级误差。照片质感与交互已开始按参考方向改善，但本地首版仍需进一步视觉打磨，不能宣称与参考效果完全一致。
